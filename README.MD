# 你不知道的注册表文件

## 描述

本知识库介绍了注册表文件的隐藏秘密，包括：

* 文件头
* 注释
* 用十六进制形式导入任意数据
* 配套的[转换器](Programs/str_to_hex.py)和模拟注册表编辑器检查和解析流程的[检查器](Programs/checker.py)

## 尝试

**警告：在进行任何注册表操作前，请务必备份好重要数据，以免出现无法还原的情况！不当的操作可能会损坏应用程序或系统！**

这些注册表文件均会往 `HKEY_CURRENT_USER\Test` 里写入注册表项和值。你需要打开注册表编辑器，并定位到 `HKEY_CURRENT_USER`，然后尝试导入 Regs 目录下的注册表文件，观察是否被导入、注册表项是否创建以及值是否被添加。

这些注册表文件均保证适用于 Windows 7/Windows Server 2008 R2 及更高版本，并适用于它们的 PE/RE 环境。

文件名后面的括号表示了预期的导入结果。

使用 `Regs\删除测试项.reg` 可以删除 `HKEY_CURRENT_USER\Test` 注册表项，以还原到添加前的状态。

## 目录结构

```
Programs
	checker.py（检查器）
    str_to_hex.py（转换器）
Regs
	文件头
    	版本
        	两个小数点的版本.reg（将会导入失败）
			两个版本字符串的文件头.reg（将会导入成功）
			在小数点前的字符.reg（将会导入失败）
			在小数点后的字符.reg（将会导入成功）
			有前导 0 的版本.reg（将会导入成功）
			错误的版本.reg（将会导入失败）
		非常规文件头
        	在末尾塞了一些字符的文件头.reg（将会导入成功）
            有多个制表符的文件头.reg（将会导入成功）
            有多个空格的文件头.reg（将会导入成功）
            没有空格的文件头.reg（将会导入成功）
            用任意字符串代替空格的文件头.reg（将会导入成功）
            用制表符代替空格的文件头.reg（将会导入成功）
		非法的文件头
        	文件头不在第一行.reg（将会导入失败）
            无文件头.reg（将会导入失败）
            未指定版本的文件头.reg（将会导入失败）
  
	REGEDIT4 格式的注册表文件.reg（将会导入成功）
	一个合法的注册表文件.reg（将会导入成功）
	删除测试项.reg（将会导入成功）
	注释.reg（将会导入成功）
	用十六进制数值导入任意类型的数据.reg（将会导入成功）
```
